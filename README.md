# Retail_sales_eda_and_dashboard
A comprehensive retail sales analysis project featuring exploratory data analysis (EDA) in Python and an interactive dashboard in streamlit to uncover revenue trends.
The link for interactive dashboard: https://retailsales-dashboard01.streamlit.app/

Introduction:
This project, titled “Sales Insight Dashboard for Retail Store using Python and Data Analytics,” focuses on performing exploratory data analysis (EDA) on retail sales data using Python and its data analysis libraries. The project involves the complete analytics workflow, including data collection, database integration, data cleaning, preprocessing, visualization, and dashboard creation.

Key findings:
- The sales analysis identified clear monthly sales in retail transactions, with certain months generating significantly higher revenue compared to others.
- Product category analysis showed that some categories contributed more to total sales and customer purchases, indicating strong customer demand for those products.
- Data cleaning and preprocessing improved the quality and reliability of the dataset by handling missing values, duplicates, and incorrect data types.
- Correlation analysis between numerical variables helped identify relationships among quantity purchased, unit price, and total sales amount.
- Payment method analysis indicated that digital payment methods were widely preferred by customers over traditional payment options.

Recommendations:
- Increase inventory and marketing efforts for high-performing product categories to maximize revenue generation.
- Introduce promotional campaigns during low-sales periods to improve overall sales consistency throughout the year.
- Improve sales strategies for underperforming products by offering discounts, bundled offers, or targeted advertising.
- Continue supporting and optimizing digital payment systems since they are preferred by many customers.

Limitations:
- The dataset used in this project may not fully represent real-world retail business complexity and customer behavior.
- Some records contained missing or inconsistent values, which required preprocessing and may affect analysis accuracy.
- The project mainly focused on exploratory data analysis and descriptive analytics rather than predictive modeling.
- The dashboard provides static historical analysis and does not currently support real-time data streaming.

Future Work:
- Integrate machine learning algorithms for sales forecasting and customer purchase prediction.
- Add real-time data integration to continuously update dashboard insights.

Conclusion:
This project successfully demonstrated the use of Python-based data analytics techniques to analyze and visualize retail sales data. Through data cleaning, preprocessing, exploratory data analysis, and dashboard development, meaningful insights were extracted from the dataset to better understand business performance and customer behavior.
